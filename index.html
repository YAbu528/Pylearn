      PYTHON CURRICULUM
      
    Explore the Python Lessons
    
      
    PyLearn teaches Python step by step, from your first variables to working with APIs and JSON. Preview the topics covered in these interactive lessons.
    
    
    
  
    

  
    
    
    
      
    1. Python Basics: Variables and print()
    
      
    Learn how variables give names to values, how assignment works, and how print() displays information.
    
    
    

    
    
      
    2. Data Types: Strings, Integers and Floats
    
      
    Understand text (str), whole numbers (int), decimal numbers (float), and how to inspect values with type().
    
    
    

    
    
      
    3. Operators and input()
    
      
    Practice arithmetic operators, receive user input, and convert text into numbers using int() and float().
    
    
    

    
    
      
    4. Conditions: if, elif and else
    
      
    Make programs choose different actions using conditions, comparison operators, if, elif, and else.
    
    
    

    
    
      
    5. Loops: for and while
    
      
    Repeat instructions with for and while loops, use range(), and learn when loops continue or stop.
    
    
    

    
    
      
    6. Functions: Reusable Code
    
      
    Create functions with def, use parameters and arguments, and return results for other code to use.
    
    
    

    
    
      
    7. Lists and Dictionaries
    
      
    Store and organize data, access list items by index, and retrieve dictionary values using keys.
    
    
    

    
    
      
    8. Errors and Modules
    
      
    Understand common errors, import Python modules, and handle exceptions using try and except.
    
    
    

    
    
      
    9. String Skills
    
      
    Work with text using indexing, slicing, string methods, and formatted strings such as f-strings.
    
    
    

    
    
      
    10. Tuples and Sets
    
      
    Use tuples for ordered data that should not change, and sets to store unique values and remove duplicates.
    
    
    

    
    
      
    11. List Comprehensions
    
      
    Create lists concisely using expressions and loops, with optional conditions to filter results.
    
    
    

    
    
      
    12. File Handling
    
      
    Read and write files with open(), use with to manage files safely, and learn common file modes.
    
    
    

    
    
      
    13. Object-Oriented Python
    
      
    Explore classes and objects, define methods, initialize objects with __init__, and use self.
    
    
    

    
    
      
    14. APIs and JSON
    
      
    Learn how APIs exchange data and how to parse JSON into Python dictionaries and lists.
